# Security Policy

## Supported Versions
This is a fast-evolving project. Please use the latest release. Security fixes may not be backported to older tags.

## Reporting a Vulnerability
Please report potential vulnerabilities via GitHub Security Advisories or by opening a private issue if available. Do not include exploit details in public issues. We will acknowledge receipt and work with you on a coordinated disclosure timeline.

## Secrets
Never commit secrets or credentials. CI runs a secret scanner (gitleaks) to help prevent accidental leaks.
